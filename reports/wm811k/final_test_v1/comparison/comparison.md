# WM-811K 동결 후보 최종 Test 결과

예정된 하나의 최종 평가 세션에서 동결 모델 상태 6개를 같은 Test로 평가했습니다. 전체 Test 접근이 1회라는 뜻이 아닙니다.
test_used_for_model_selection=false는 이번 동결 절차의 범위를 뜻합니다. 과거 Test와 현재 Test의 표본 겹침은 미확인이며 이 값이 과거 이력을 증명하지 않습니다.

- ResNet18은 고정 학습률, SmallWaferCNN은 ReduceLROnPlateau입니다. 튜닝 구성 비교이며 구조만의 효과가 아닙니다.
- 종합후보 지정은 Test 이전의 사용자 결정입니다. 이 결과로 모델·설정·seed를 다시 고르지 않습니다.
- 같은 Test 표본을 seed별로 반복 평가했으므로 독립 표본이 늘어난 것이 아닙니다. 평균 차이를 통계적 우월성으로 해석하지 않습니다.
