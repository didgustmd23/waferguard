# ResNet18+D4 학습률 스케줄 대조: plateau_alpha0_75

**선정 상태: 선정 보류.** 합격 기준을 정하지 않았으므로 자동으로 채택하지 않고 지표만 나란히 보여 줍니다. 최종 판단은 사용자가 합니다.

Test는 사용하지 않았습니다. 추가 튜닝에 쓴 Validation 결과이므로 일반화 성능이나 통계적 우월성을 뜻하지 않습니다. seed별 저장 selected_epoch 혼동행렬로 계산했고 재추론은 없습니다.

기준과 후보의 실행 코드 식별값이 **다릅니다**. 차이 파일: `train.py`. 고정 학습률 경로의 계산 동등성은 합성 검증 범위이며, 실제 신구 학습의 동등성은 측정하지 않았습니다.

- 기준 코드: `1aaf425fdbbd0e771ba5a2b5f962f1b3c2fd1b497a721fa829f63b3346fea896`
- 후보 코드: `31e7f2cbf7e4b5d6884fdb5bc7df23708dd9090fd43720e8d0b08565f815548e`
- 캐시: `d967b8737aaf375d6c3066fb7cb87c068a8580ad0439068f4815e23ffc0269cb`

해시는 혼용·변경 확인용이며 인증이 아닙니다. 파일별 입력 식별값은 `comparison.json`의 `input_digests`에 있습니다.
