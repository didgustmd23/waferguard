# WaferGuard 프로젝트 마무리 일정

작성일: 2026-10-09. 최종 기한: **2026-11-05**.

사용자가 정한 일정은 2026-10-12~2026-10-18 딥러닝 전처리, 2026-10-19~2026-10-25 에이전트 구현, 2026-10-26~2026-11-05 통합 테스트·보고서·발표자료 준비다. 기존 SECOM 머신러닝은 마무리 상태로 보존한다. 체크는 명시한 범위의 완료 근거가 있는 항목에만 적용하며, 부분 완료·미확인·보류는 체크하지 않는다. 현재 상태 기준일은 2026-10-23이다.

## 1. 기간별 목표

| 기간 | 주요 작업 | 담당 | 완료 기준 |
| --- | --- | --- | --- |
| 10/12~10/18 | WM-811K 딥러닝 전처리 | 양현승, 이종수 인수·검토 | 품질·분할·변환·캐시·Dataset 검증과 첫 배치 전달 |
| 10/19~10/25 | 사용자 승인형 범용 전처리 에이전트 | 양현승 | 공통 조정·표형 통합 작업·권장안/질문·승인·제한적 복구, 보안 회귀 검증 |
| 10/26~11/05 | 통합 테스트·보고서·발표자료 | 공동, 담당 영역별 작성 | 재현 가능한 실행·평가·보안 검증 기록, 최종 보고서·발표자료·시연 준비 |

딥러닝 모델·학습·평가는 기존 담당인 이종수가 진행한다. 전처리 인수 후 에이전트 구현과 병행하며, 구체적인 모델 실험 일정과 동결일은 학습 환경·기준선 결과 확인 후 조율한다. 에이전트가 완성될 때까지 학습을 기다리지 않도록 전처리 코어는 단독 실행 가능하게 만든다.

## 2. 2026-10-12~2026-10-18: 딥러닝 전처리

기준 문서: [WM 전처리 상세 설계](WM811K/PREPROCESSING_DESIGN.md).

- [ ] 원본 출처·신뢰 여부·실제 구조·자원 요구량 확인.(실제 구조·변환 경로는 확인됨. 출처·신뢰 판단과 자원 확인 전체의 명시적 완료 근거는 추가 확인 필요.)
- [x] 원본 읽기·canonical 변환·라벨 정규화 구현.
- [x] 맵 값·라벨·미라벨·Lot·중복·제외 사유 검사.
- [x] 클래스·맵 크기·Lot 분포와 대표 패턴을 로컬에서 확인.
- [x] Lot·중복 보호 분할과 비중첩·클래스 지원 검증.
- [x] 2채널 입력·resize·마스크 보존·캐시·Dataset 구현 및 검증.(실제 Train·Validation 캐시/첫 배치 범위. Test 캐시·학습은 제외.)
- [ ] 변환·클래스 매핑·분할 계약과 첫 배치를 이종수에게 전달하고 인수 확인.(전달 규격·첫 배치 확인은 완료. 담당자 인수 확인은 미확인.)

완료 근거는 [WM 결과 보고서](../reports/wm811k/report.md)의 실제 실행·분할·변환·캐시 결과와 [캐시·Dataset 실행 확인](WM811K/CACHE_DATASET.md#실행-확인-기록--2026-10-10)이다. 실제 데이터를 다시 읽거나 재실행한 것은 아니다.

10/18 완료 기준은 코드 작성만이 아니라 합성 입력 검증과 승인된 실제 입력의 처리 결과·전달 계약 확인이다. 원본 역직렬화의 신뢰·격리 조건이 충족되지 않으면 실행하지 않고 미충족 조건을 기록한다.

## 3. 2026-10-19~2026-10-25: 에이전트 구현

기준 문서: [에이전트 단일 설계](agents/DESIGN.md)(보안 기준 SEC-01~16 포함). 현재 지원·검증 상태는 [사용 안내](agents/GUIDE.md)를 따른다.

- [x] 전처리 도구 계약을 연결한 등록 모듈·고정 계획 실행 구현.
- [x] 원본·분할·변환 계획 승인과 정확한 작업에 결합한 승인 검증 구현.
- [x] 로컬 기록·체크포인트·완료 결과 검증/재사용과 제한적 복구 구현.(입력 실패 후 계획 수정·완료 저장 실패 복구 범위.)
- [ ] 일반적인 중단/재시작·재접속 복구 구현.(제한적 복구와 구분. 후속 보류.)
- [x] LLM 권장안·질문·응답 계약 검증과 고정 계획 범위의 실행 조정 구현.
- [x] 요청·응답/토큰 예산·자동 재시도 제한과 실패 사유/다음 행동 안내 구현.(유료 API 비용 관리 기능은 미지원.)
- [x] 합성 fixture·mock provider 기반 보안/기능 회귀 검사 수행.(최신 전체 회귀 1151개 실행·1138개 통과·실패 0·오류 0·생략 13, passed. bool 라벨 보완 포함. 근거·생략 범위는 GUIDE 참조.)
- [x] OS 격리·네트워크·provider 정책의 확인 범위와 미완료 항목 기록.(실제 격리 정상 경로와 전체 egress 검증 완료는 구분.)

초기 최소 상태 매핑·`bounded_llm` 도구 선택기는 현행 통합 작업과 다른 미활성 설계이며 완료로 표시하지 않는다. 현행은 동의 범위의 목표·허용 컬럼명/집계로 권장안을 받고, 로컬 검증·고정 실행기가 실행을 통제한다. 원본 행·맵·경로·승인 정보·전체 로그의 자동 전달 금지는 유지한다. mock 검증 통과를 실제 OS 격리·egress의 전면 검증으로 표시하지 않는다. 검증 상태·간헐 실패·현재 제한의 기준은 [GUIDE](agents/GUIDE.md#검증-상태와-남은-제한)다.

- [x] 배열·이미지 형태의 통합 작업 연결.(단일 `.npz` 표본 묶음 범위. bool 라벨·실제 격리 실행·메모리 기본 용량/옵션/dtype·제한 초과 대응 확인. 일반 이미지 폴더·모든 크기/형상 지원을 뜻하지 않음.)

배열 통합 연결은 위 범위에서 완료했고, 웨이퍼 프로파일 연결 → 시간 처리 지원은 후속으로 남아 있다. 최신 회귀·실제 격리·WFP 시험의 근거와 한계는 GUIDE에 모으며, 다른 일정 항목의 완료로 확대 해석하지 않는다.

## 4. 2026-10-26~2026-11-05: 테스트·보고서·발표자료

- [ ] 전처리 코어 단독 실행과 에이전트 실행의 필수 계약·결과 정합성 확인.
- [ ] 정상 완료·품질 실패·승인 대기·중단/재개·금지 요청 차단 통합 시연.
- [ ] 딥러닝 모델·전처리·평가 정책 동결 후 최종 평가와 저장·복원 검증.
- [ ] 보안 검증 SEC-01~16의 통과·실패·미검증·범위 제외를 근거와 함께 정리.
- [ ] SECOM·WM-811K의 독립 평가 결과, 한계, 설계 목적을 최종 보고서에 통합.
- [ ] 발표자료·시연 순서·재현 명령·환경 준비 사항 작성.
- [ ] 문서 링크·그림·용어·수치·오타와 공개 가능한 산출물 점검.
- [ ] 11/05까지 최종 제출본과 발표용 자료 준비.

두 데이터셋은 웨이퍼 단위로 연결되지 않으므로 통합 검출률이나 실제 2단계 성능을 주장하지 않는다. 평가 결과에 맞춰 Test를 반복 최적화하지 않는다. 발표자료는 딥러닝 결과가 정리된 뒤 확정한다.

## 5. 일정 운영 원칙

지금의 우선순위는 딥러닝 전처리 완성 → 학습 담당자 전달 → 에이전트 연결이다. 보안 단위 검증은 구현과 동시에 하고 마지막 기간에는 통합·환경 검증을 진행한다.

11/02부터 신규 기능 추가를 멈추고 오류 수정·보고서·발표 준비에 집중하는 것을 권장한다. 이는 사용자 확정 일정과 구분한 운영 제안이다. 지연 시 고급 모델·추가 LLM 기능·외부 추적 시연을 줄이고 데이터 계약·승인·원본 보호·필수 검증을 우선한다. 기한 때문에 보안 조건을 낮추거나 미검증 항목을 완료 처리하지 않는다.
