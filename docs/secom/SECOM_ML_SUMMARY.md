# SECOM 머신러닝 실험 마무리

- 정리일: 2026-10-09
- 상태: **V2 개발 실험 종료·연구용 주후보와 비교 시나리오 정리 완료**
- 범위: V2 비교 실험 정리와 후속 고정 센서 개발 검증·90%/80% 시나리오 저장·복원·추론 데모. 실제 학습·저장 명령은 사용자가 실행했으며 독립 최종 Test는 이번 마무리 작업에서 사용하지 않았다.
- 프로젝트 역할: 공정 센서로 위험 대상을 선별하고, 별도 WM-811K 과제로 검사 이후 결함 패턴 진단을 연구한다.

## 1. 결론과 선택 이유

아래 평균 AP와 합산 Recall은 **구간마다 센서를 재선택한 3구간 비교 실험**의 결과다. 저장된 고정 센서 후보의 한 개발 구간 결과는 8절에 별도로 기록했다. 저장 후보의 90%/80% 문턱과 3구간 모델의 문턱을 혼용하지 않는다.

연구용 주후보는 **중앙값 대치 + 반복 weighted gain Top-20 + XGBoost 깊이 2·L2 규제 1**이다. 미검 최소화를 우선한다는 사용자 결정에 따라 규제 5는 선별 부담 비교 후보로 보존한다.

주 시나리오는 **과거 시간순 OOF Recall 목표 90%**, 부담 비교 시나리오는 **80%**다. 문턱은 각 외부 학습 구간 안의 OOF에서만 선택하며, 이후 구간의 정답으로 문턱을 맞추지 않는다. 선별 상한 40%를 제외한 진단 시나리오이며 기존 `config.json`의 80%·40% 정책을 충족하거나 대체한 결과가 아니다.

주후보의 평균 AP는 **0.171439 ± 0.050729**, 전체 센서 기준은 **0.174873 ± 0.133225**다. 평균 AP 상대 하락은 **1.96%**로, 센서 20개 이하와 AP 하락 목표 20% 이내를 충족했다. 이 비율은 정확도나 개별 구간의 동일 성능을 뜻하지 않는다.

OOF 목표 90% 문턱을 이후 시간 구간에 적용한 합산 Recall은 **94.87%**지만 선별 비율은 **92.23%**다. 미검을 줄이는 대신 거의 전수검사에 가까운 후속 확인 부담이 생겼다. 이를 효율적인 현장 검사나 배포 성능으로 주장하지 않는다.

## 2. 데이터와 평가 범위

- 입력: `data/splits/integrated/time_train.csv`, 1,096행·불량 78행.
- 외부 평가: Train 내부의 확장형 시간순 3구간. 평가 합계 824행·정상 785행·불량 39행.
- 각 과거 학습 구간의 시간순 내부 OOF: 2구간. 초기 미예측 행은 제외하며 정상이나 0점으로 채우지 않는다.
- 품질 필터·대치·센서 선택·가중치 계산은 각 학습 범위에서만 fit한다.
- AP는 외부 구간별 평균·표준편차다. Recall·선별 비율은 TP/FP/FN/TN 합산으로 계산한다. 표준편차는 신뢰구간이 아니다.
- V2 개발 중 외부 구간 결과를 반복 비교해 후보를 골랐다. 이 구간들은 독립적인 미사용 최종 Test가 아니다. V1의 과거 Test 사용 이력도 지우지 않는다.

## 4. 주후보 설정과 센서 선택

- 품질 제거: 학습 구간에서 결측률 50% 초과 센서를 먼저 제거하고, 남은 센서에서 관측값 종류 1개 이하 센서를 제거한다.
- 선택기: 클래스별 계층 bootstrap 5회. 각 재표집에서 품질 필터·median·gain 선택용 XGBoost를 학습한다. 선택 빈도 내림차순 → 평균 순위 오름차순 → 원래 센서 순서로 20개를 선택한다.
- 선택용 XGBoost: 깊이 3·규제 1, 불량 가중치는 해당 학습 정상/불량 비율.
- 최종 분류기: 깊이 **2**·`reg_lambda=1`, 트리 300개·학습률 0.05·subsample/colsample_bytree 0.8·seed 42·hist. 불량 가중치는 해당 학습 정상/불량 비율.
- 최종 경로: 품질 필터 → 반복 gain 선택 → median 대치 → XGBoost. XGBoost 경로에는 scaling을 강제하지 않는다.
- 반복 선택 내부의 대치와 최종 분류기 입력 대치는 서로 다른 fit 범위에 속한다. 최종 분류기만 깊이를 바꿨으며 선택기와 전체 센서 기준은 유지했다.

현재 20개는 **학습 구간마다 선택한 20개**다. 고정된 동일 센서 20개가 모든 이후 구간에서 같은 성능을 낸다는 검증은 아니다. 전체 Train의 `candidate_features.csv`도 후보 목록이며 최종 동결 목록이 아니다.

반복 선택의 구간 간 공통 Top-20은 0·1·2개로 여전히 작았다. 반복 resampling이 구간 간 센서 목록의 안정성을 보장한다고 주장하지 않는다. 실제 분포 변화와 소표본·상관 센서·선택 변동을 구분해 해석한다.

근거: `feature_run.json`, `bootstrap_records.csv`, `selected_features.csv`, `candidate_features.csv`, 기존 [V2 실험 안내](EXPERIMENT_NOTES.md).

## 5. 같은 OOF Recall 목표 80%에서의 모델 비교

각 과거 내부 OOF에서 Recall 80% 이상인 저장 후보 중 선별 비율 최소 → Precision 최대 → threshold 최대 순으로 선택하고, 해당 외부 모델의 이후 시간 구간 예측에 적용했다. 원래 로그의 F1 최대 `temporal_oof` 요약과 구분한다.

| 모델 | 이후 Recall | 선별 비율 | TP | FP | FN | TN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 전체 센서 기준 | 84.62% | 64.08% | 33 | 495 | 6 | 290 |
| 반복 Top-20·깊이 3·규제 1 | 84.62% | 66.87% | 33 | 518 | 6 | 267 |
| 반복 Top-20·깊이 2·규제 1 | **89.74%** | 77.55% | **35** | 604 | **4** | 181 |
| 반복 Top-20·깊이 2·규제 5 | 82.05% | **61.89%** | 32 | **478** | 7 | 307 |

규제 1은 규제 5보다 불량 3건을 더 검출하고 정상 126건을 더 선별했다. 사용자는 정상 추가 검사 부담보다 불량 유출 위험 감소를 우선한다고 결정했다. 이는 현장 비용이 실제 측정됐다는 의미가 아니다.

근거: 세 반복 Top-20 실험 폴더의 `threshold_compare.csv`, `oof_predictions.csv`, `predictions.csv`. XGBoost float32 점수의 CSV 왕복 경계값을 복원해 문턱 비교했고 내부 OOF TP/FP가 저장 후보와 일치하는지 확인했다. 재학습하지 않았다.

## 6. 주 시나리오 90%와 부담 비교 80%

| 과거 OOF 목표 | 이후 Recall | 선별 비율 | 선별 건수 | TP | FP | FN | TN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 80% — 부담 비교 | 89.74% | 77.55% | 639 | 35 | 604 | 4 | 181 |
| **90% — 미검 우선** | **94.87%** | **92.23%** | **760** | **37** | **723** | **2** | **62** |

90% 시나리오는 불량 2건을 더 검출하기 위해 정상 119건을 추가 선별했다. 2차로 전달한다고 가정하는 대상은 정상 723건만이 아니라 불량 37건을 포함한 **760건**이다. 1차 미검 2건은 선별 대상에 포함되지 않는다.

### 구간별 결과와 문턱

| 구간 | 80% 목표 문턱 | 이후 Recall / 선별 비율 | 90% 목표 문턱 | 이후 Recall / 선별 비율 |
| --- | ---: | --- | ---: | --- |
| 1 | 0.005796277150511742 | 95.45% / 90.32% | 0.002746967598795891 | 100.00% / 96.06% |
| 2 | 0.024326928183436396 | 87.50% / 60.81% | 0.006481254901736975 | 87.50% / 87.55% |
| 3 | 0.018942609466612338 | 77.78% / 81.25% | 0.008934700693935156 | 88.89% / 93.01% |

이 값들은 서로 다른 구간 모델의 문턱이다. 평균이나 마지막 값을 단일 최종 모델의 문턱으로 사용하지 않는다. 과거 OOF 목표 90%가 이후 각 구간의 Recall 90%를 보장하지 않으며 소수 불량 1건이 구간 Recall에 큰 영향을 준다.

근거: OOF 문턱 후보 (로컬: `logs/secom/v2/v2_p0_stable_gain_top20_depth2/threshold_compare.csv`), 내부 OOF 예측 (로컬: `logs/secom/v2/v2_p0_stable_gain_top20_depth2/oof_predictions.csv`), 이후 구간 예측 (로컬: `logs/secom/v2/v2_p0_stable_gain_top20_depth2/predictions.csv`).

## 7. WM-811K로 넘기는 범위

1차는 위험 선별, 2차는 검사 이후 웨이퍼맵의 결함 패턴 진단과 검토·추가 검사 권고다. 실제 연결 데이터가 없으므로 독립 성능 평가와 가상 흐름 데모를 구분한다.

- WM-811K는 광학 사진이 아니라 다이별 검사 결과 맵이다. 맵 확보에 필요한 검사를 생략했다고 주장하지 않는다.
- `None` 패턴은 출하 가능한 정상 웨이퍼를 보증하지 않으며 센서 경고를 자동 해제하지 않는다.
- 760건의 실제 WM 2차 처리 결과, 정상 복구 건수, 통합 Recall·불량 유출 감소율은 검증하지 않았다.
- 이미지 부재·불확실성은 추가 검토 경로로 보낸다는 설계이며 아직 구현 완료가 아니다.

상세 역할·담당·독립 평가 기준은 [WM 기초 설계](../WM811K/PREPROCESSING_DESIGN.md)를 따른다.

새 미사용 데이터의 독립 검증과 동일 웨이퍼 센서·검사맵·최종 결과의 실제 통합 검증은 향후 확장 과제다. 현재 ML 실험 종료의 필수 미완료 작업으로 취급하지 않는다.

후속 고정 센서 검증은 사용자 실행으로 완료했다. 551행에서 센서를 선택하고 824행으로 분류기를 학습해 마지막 개발 구간 272행·불량 9건에서 평가했다. 고정 후보의 AP는 0.323619, ROC-AUC는 0.795944였다. 선택 이후 과거 OOF에서 정한 80% 문턱은 이후 TP 8·FP 129·FN 1·TN 134, 90% 문턱은 TP 9·FP 248·FN 0·TN 15였다. 한 개발 구간의 결과이며 앞 절의 구간별 재선택 모델 합산 결과와 구분한다. [선택 시점·대조 경로·실행 안내](EXPERIMENT_NOTES.md)를 참고한다.

후속 고정 후보의 90%·80% 모델 묶음 저장과 별도 프로세스 복원 검증을 완료했다. 각 33행 검증에서 확률 차이는 0.0이고 판정·라벨이 일치했다. 공통 Train 유래 데모 입력 33행에서는 90%가 33행, 80%가 30행을 선별했다. 이는 추론 기능 데모이지 성능 평가가 아니다. 저장 경로·정확한 문턱·실행 결과는 [V2 Model Card](model_card_v2.md), 재현 명령은 [실행 안내](USAGE.md#v2-시나리오-저장복원)를 따른다.

후속 학습·저장·데모는 사용자가 명령을 실행했다. 현재 산출물은 **개발 실험 결론과 고정 센서 연구용 후보 묶음**이며 독립 최종 평가·배포 완료가 아니다. V1 저장 묶음은 계속 retired 상태로 보존한다.

## 9. 발표용 결론

### 기존 Test 후속 비교와 팀원 후보 점검

저장 고정 모델의 기존 Test 236행·불량 9건 평가를 완료했다. V1 Recall 11.11%(TP 1·FP 30·FN 8)에 대해 V2 90% 목표는 Recall 100%(TP 9·FP 215·FN 0, 선별 94.92%), V2 80% 목표는 Recall 66.67%(TP 6·FP 103·FN 3, 선별 46.19%)였다. V2 AP는 0.075077, ROC-AUC는 0.682330이다. 개발 구간의 88.89%를 기존 Test 결과로 쓰지 않는다. V1 결과를 참고한 개발 이력이 있어 완전 미사용 독립 평가로 주장하지 않는다.

팀원 LightGBM gain Top-20을 같은 시간순 조건에서 비교했다. 평균 AP는 기존 반복 gain 0.171439, 팀원 0.123767이었다. 동일 OOF 목표 80%·90%에서 기존 방식이 검출 건수는 많고 정상 오탐은 적어 기존 V2를 유지하고 팀원 후보는 비교 이력으로 보존했다. 이 비교는 구간별 센서 재선택 실험이며 위 고정 모델 Test와 구분한다.

최종 결론은 **같은 기존 Test에서 V1 대비 검출 능력은 개선됐지만 높은 Recall과 낮은 선별 부담을 동시에 달성하지는 못했다**는 것이다. ML 실험·저장·추론·기존 Test 비교는 마무리하고 최종 그림·발표 자료를 별도로 준비한다. 상세 수치와 출처는 보고서 35.5·36절을 따른다.

### 구간별 재선택 실험의 보조 발표 문구

고정 센서 저장 후보의 인계 문서는 [V2 Model Card](model_card_v2.md)를 따른다. 아래 발표 문구는 구간별 센서 재선택 비교 실험에 대한 결론이며 저장된 한 모델의 독립 Test 성능이 아니다.

> SECOM의 결측·불균형·시간 변화를 고려해 학습 구간 내부에서 전처리와 센서 선택을 수행했다. 반복 gain 선택과 분류기 깊이 조정으로 20개 센서 모델의 평균 AP를 전체 센서 기준 대비 1.96% 하락 이내로 유지했다. 미검 우선 OOF 시나리오의 이후 시간 구간 합산 Recall은 94.87%였지만 선별 비율도 92.23%로 높았다. 이를 독립적인 최종 Test나 검사 효율 개선으로 주장하지 않고, 별도 웨이퍼맵 패턴 진단 과제로 확장하는 연구 프로토타입으로 정리했다.
