# 형식 독립 입력 복사본과 파일 크기 상한

`src/agents/input_snapshot.py`는 형식과 무관하게 로컬 일반 파일 하나를 새 작업 폴더에 바이트 그대로 복사한다. 원본은 수정하지 않으며 내용 해석·EDA·worker·LLM 호출·승인 발급을 수행하지 않는다. 기존 고정 합성 EDA 경로도 변경하지 않는다.

## 사용법

프로젝트 루트에서 사용자가 복사할 파일을 명시한다. 다음 경로는 예시이며 실제 파일로 교체한다. CSV·Parquet·NPZ·pickle·확장자 없는 파일도 동일하게 복사하며 형식의 유효성을 보증하지 않는다.

```powershell
python -m src.agents.input_snapshot --input D:/datasets/example.csv --name csv-input01 --max-input-mib 1024 --confirm-local-copy
```

`--max-input-mib`는 필수인 파일 바이트 크기 상한이다. 1024MiB는 1GiB이며 worker의 `--memory-mib`와 별개다. 상한이 정확히 같은 크기는 허용한다. 파일을 청크 단위로 복사하며 메모리에 전체를 올리지 않는다.

사전 초과 시 다음 정보를 로컬 터미널에 표시하고 종료 코드 2로 종료한다.

```text
입력 파일이 설정한 크기 상한을 초과했습니다.
확인한 파일 크기: 1250.00 MiB
허용 상한: 1024.00 MiB
파일을 복사하거나 EDA를 실행하지 않았습니다.
더 큰 파일이 필요하면 --max-input-mib 값을 조정한 뒤 새 작업으로 요청하세요.
```

자동 상한 증가·데이터 자르기·표본 추출은 하지 않는다. 복사 도중 상한을 넘으면 중단하고 부분 결과 사용 금지를 안내한다. 탐지 시점의 크기는 전체 최종 크기가 아니라 읽기 검사에서 확인한 크기일 수 있다.

## 결과와 검증

저장 위치는 `logs/agents/input_snapshots/<name>/`로 고정한다. 새 이름만 허용하며 기존 폴더를 덮어쓰지 않는다.

- `input.bin`: 바이트 정합성을 검증한 복사본. 원본 이름·확장자를 보존하거나 추정하지 않는다.
- `snapshot.json`: 버전·크기·SHA-256·요청한 파일 상한. 원본 경로·컬럼·내용은 기록하지 않는다.
- 실패 시 `input.bin.part` 등이 남을 수 있다. 완료 manifest 없는 부분 결과는 사용하지 않으며 자동 삭제하지 않는다.

로컬 절대 경로·일반 파일·비어 있지 않은 입력을 요구하며 링크·하드 링크·경로 이탈 형식은 거부한다. 열린 원본의 식별값·크기·수정 시각을 확인하고 같은 파일 재읽기 해시, 복사본 해시를 대조한다. `verify_snapshot(directory, expected)`는 외부에 보존한 `Snapshot` 기대 계약과 실제 복사본을 재대조한다. manifest 자체를 승인 증명으로 신뢰하지 않는다.

계약 버전은 `file_snapshot_v1`, 내용 식별값은 `file_snapshot:<SHA-256>`이다. 과거 `csv_snapshot_v1`·`input.csv` 결과는 자동 변환·삭제하거나 새 계약으로 재사용하지 않는다. 필요하면 원본에서 새 이름으로 준비한다.

복사 허용과 분석 허용은 별개다. 내용 해석은 별도 프로파일에서 선택한 등록 어댑터가 담당한다. 지원하지 않는 형식은 복사만 가능하며 자동 분석하지 않는다. pickle도 이 모듈에서는 역직렬화하지 않으며, 복사 성공은 pickle 읽기 승인이나 안전성 인증이 아니다. 폴더·여러 파일 묶음·압축 해제는 이번 범위가 아니다.

이 단계는 악의적인 동시 파일 변경을 완전히 방어하거나 복사본을 OS 수준에서 불변으로 만드는 기능이 아니다. worker 전달 직전 검증·읽기 전용 ACL·프로파일 및 승인 결합은 다음 단계다. 입력 크기 상한은 반복 복사·누적 디스크 용량·EDA 메모리 사용량을 제한하지 않는다. 해당 정책은 별도로 관리한다.

원본·복사본·크기·해시·경로는 로컬 전용이다. 이 모듈에는 외부 전송 경로가 없다.

복사본과 등록 어댑터·컬럼 역할·EDA 설정·자원 요청을 묶는 [EDA 입력 계약](EDA_INPUT_CONTRACT.md)과 [승인 CLI·격리 worker 연결](../guides/SNAPSHOT_EDA.md)을 추가했다. 합성 연결 검증을 통과했으며 새 경로의 실제 AppContainer 실행은 별도 확인한다.

```powershell
python -m unittest tests.agents.test_input_snapshot -v
```
